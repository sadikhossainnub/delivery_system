1. Executive Summary & Architecture

The Delivery System custom app provides seamless, production-ready integration between ERPNext v15/v16 and Bangladeshi courier services (starting with Steadfast Courier, with pluggable support for Pathao, RedX, Paperfly, and eCourier).

Key Operational Highlights
  • One-Click & Bulk Booking: Book orders directly from Sales Order or Delivery Note forms or in bulk (up to 500 per batch) from List Views.
  • Automated Real-Time Tracking: Automated 30-minute status polling plus inbound webhook listener for instant status updates.
  • Automated Accounting: Automatic Journal Entries for courier clearing, Payment Entries for payouts, delivery charge splitting, and variance adjustments.
  • 8 Script Reports & Dashboard: Complete suite of delivery, stuck parcel, reconciliation, and financial performance reports.

2. Installation & Configuration Guide

2.1 Installation Steps

To install the app on your Frappe bench and target site:

# 1. Fetch the repository
bench get-app delivery_system https://github.com/sadikhossainnub/delivery_system.git

# 2. Install on target ERPNext site
bench --site erp.yourdomain.com install-app delivery_system

# 3. Run database migrations
bench --site erp.yourdomain.com migrate

2.2 Courier Settings Setup

  1. Navigate to Delivery System > Courier Settings in Desk.
  2. Set Default Provider to Steadfast.
  3. Set Booking Source DocType:
    • Both: Allow booking from both Sales Order and Delivery Note.
    • Sales Order: Restrict booking to Sales Orders only.
    • Delivery Note: Restrict booking to Delivery Notes only.
  4. Check Enable Accounting Automation (enabled by default).
  5. Set Auto Post Variance Threshold (e.g., 50.0 Taka).

3. Parcel Booking & Tracking Operations

3.1 Single Parcel Booking

  1. Open a submitted Sales Order or Delivery Note.
  2. Click the Send to Courier button in the top action bar.
  3. Review recipient details in the modal dialog:
    • Recipient Phone: Must be a valid 11-digit Bangladeshi mobile number (e.g., 01712345678).
    • Recipient Address: Automatically truncated to 250 characters max.
    • COD Amount: Defaults to document grand total.
    • Delivery Type: Home Delivery (HD) or Point Delivery (PD).
  4. Click Book Courier. The system auto-creates and submits a Delivery Order, registers the consignment with Steadfast, and populates the Consignment ID and Tracking Code.

3.2 Bulk Booking from List View

  1. Go to Sales Order List or Delivery Note List.
  2. Select multiple submitted orders via checkboxes.
  3. Click Actions > Send Selected to Courier.
  4. The app processes orders in batch (up to 500 items) and displays a detailed success/failure summary.

3.3 Status Lifecycle & Badges

3.4 Inbound Webhooks & Status Polling

  • Background Scheduler: sync_pending_deliveries runs every 30 minutes to refresh non-terminal orders.
  • Inbound Webhook Endpoint: Configure https://your-site/api/method/delivery_system.webhook.steadfast_webhook in Steadfast merchant panel for real-time push updates.

4. Automated Accounting & Reconciliation

4.1 Automated Journal & Payment Entries Flow

The app automates all GL postings using standard ERPNext accounting APIs without requiring manual bookkeeping:

Phase 1: Delivery Confirmation (Clearing Entry)
When an order is marked delivered, the system posts a Journal Entry:
Debit: Steadfast Clearing Account (Asset) [COD Amount]
Credit: Debtors (Customer Receivable) [COD Amount]
Effect: Transfers receivable from customer to courier clearing account.
Phase 2: Payout & Delivery Charge Posting
When Steadfast releases a payout batch:
  • Net Payout: Payment Entry (Debit: Bank Account / Credit: Clearing Account)
  • Delivery Charges: Journal Entry (Debit: Delivery Charges Expense / Credit: Clearing Account)
Effect: Clearing account nets to zero for all reconciled consignments.
Phase 3: Variance & Cancellation Reversals
  • Small Variance (≤ 50 Taka): Auto-posted to Courier Variance account.
  • Large Variance (> 50 Taka): Flagged in COD Reconciliation report for manual review.
  • Order Cancellation Post-Delivery: Automatically posts an equal-and-opposite reversal Journal Entry.

6.2 Adding a New Courier Service

To integrate a new courier (e.g., Pathao or RedX):

  1. Create delivery_system/couriers/mycourier.py implementing BaseCourierClient.
  2. Register the module mapping in REGISTRY inside delivery_system/couriers/__init__.py: 
    REGISTRY = {
    "steadfast": "delivery_system.couriers.steadfast",
    "mycourier": "delivery_system.couriers.mycourier",
}
  3. Add a fixture record in Courier Provider with provider_code = "mycourier". No core code refactoring required!
